## ⚡ What is an AI_OS?

Most developers and founders use AI assistants (ChatGPT, Claude, Cursor) by opening a fresh chat window every morning, dumping dozens of raw files, and re-explaining context over and over again.

An **AI_OS** transforms your local workspace into a permanent, deterministic AI Operating System. When you launch **Antigravity IDE** or **Claude Code CLI**, your model loads 100% of your company memory, architecture rules, and active task state in zero seconds. It operates as an **Operating Co-Founder & Swarm Orchestrator** rather than a disposable chat tool.

## 🚀 The 3-Step Setup (20-Minute Quickstart)

### Step 1 — Create the 9-Folder Memory Hierarchy

The numbering is intentional — agentic models read file systems in sequential order. `01_memory` loads before `09_docs`:

```
YourWorkspace/
├── 01_memory/      ← Permanent context, past decisions, state logs (MEMORY.md)
├── 02_skills/      ← Reusable workflows and execution recipes (SKILL.md)
├── 03_prompts/     ← Tested high-conversion prompt templates
├── 04_projects/    ← Your active codebase repositories or symlinks
├── 05_content/     ← Content engine, social pipelines, publish registries
├── 06_agents/      ← Multi-agent swarm executive director definitions
├── 07_templates/   ← Scaffolding starters for recurring deliverables
├── 08_mcp/         ← Model Context Protocol server configs (external tools)
└── 09_docs/        ← Master plans, architecture blueprints, roadmaps
```

---

### Step 2 — Write Your Executive Brief (`CLAUDE.md` / `AGENTS.md`)

Save a single `CLAUDE.md` (and `AGENTS.md`) at the root of your workspace. It defines who you are, what you are building, and non-negotiable decision rules.

#### Key Sections:
1. **Operating Principles:** Determinism over prediction, state machines for >3 state flows, hard gates before soft gates.
2. **Model Tier Routing:** Zero metered spend rule (Tier 0 Task Scheduler → Tier 1 Python Scripts → Tier 2 Linters → Tier 3 Free Gemini/Codex → Tier 4 Claude/Gemini Pro for judgment).
3. **Context Preprocessing:** Never dump raw bulk logs. Use lightweight 50-line AST digest summaries.

---

### Step 3 — Boot Your Autonomous Multi-Agent Swarm

Run one terminal command inside your workspace:

```bash
# Using Antigravity IDE or Claude Code CLI
claude
# or
antigravity
```

The model automatically parses `CLAUDE.md` and your `06_agents/` executive layer:
* **Chief of Staff:** Executive orchestration and founder interface
* **Engineering Director:** Code health, test verification, CI/CD
* **Growth Director:** Acquisition, funnels, copy
* **Research Lead:** Market intelligence and model benchmarks
